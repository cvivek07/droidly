Android Machine Coding Interview Questions

The machine coding round asks you to build a small, working piece of an app in 30–60 minutes: a cache, a rate limiter, a state machine or a screen. These problems are written in Kotlin and come with hints, an approach, automatic tests and a reference solution. Solve them in the browser editor with a timer, like the real round.

By Vivek Choudhary, Android engineer · Updated October 2026

How to approach a machine coding round

  1. Restate the problem and agree on the APIWrite the class and function signatures first, and confirm edge cases: empty input, capacity 1, invalid arguments.
  2. Pick the data structures out loudSay why: a HashMap for O(1) lookup, a linked list for order, a sealed class for states. Interviewers grade the reasoning.
  3. Get a correct version workingClean, readable Kotlin beats a clever half-finished solution. Run it against small examples as you go.
  4. Handle the edge cases and threadingMost Android machine coding rounds ask what happens with concurrent calls, lifecycle changes or failures.
  5. Talk about trade-offs and testsExplain complexity, what you would change for production, and how you would unit test it.

Pagination Manager in Kotlin

Write a pagination manager in Kotlin: pages, navigation and bounds checks. A common Android machine coding round question, solved in the browser and checked by tests.

By Vivek Choudhary, Android engineer · Updated October 2026

EasyAbout 25 min8 automatic tests

Problem

Implement a Pagination Manager that splits a dataset into pages and supports navigation.

Functional Requirements
  • getPage(pageNumber) — Return the correct slice of items for that page (1-indexed)
  • nextPage(current) — Return the next page or null if on last page
  • previousPage(current) — Return the previous page or null if on first page
  • Each Page object carries: items, currentPage, totalPages, hasNext, hasPrevious
  • Page numbers outside 1..totalPages throw IllegalArgumentException

Example

// 23 items, pageSize = 5 → 5 pages
// Page 1: [1,2,3,4,5]
// Page 5: [21,22,23]  ← last page may be smaller

What the tests check

  • page 1 has the first 5 items
  • total pages rounds up (23 items / 5 = 5 pages)
  • last page holds the remainder
  • hasNext / hasPrevious on first, middle and last page
  • nextPage and previousPage navigate
  • nextPage on the last page and previousPage on the first return null
  • exact division has no empty last page
  • out-of-range page numbers throw IllegalArgumentException

Hints

Hint 1

Total pages = ceil(totalItems / pageSize). Use integer math: (totalItems + pageSize - 1) / pageSize

Hint 2

For page N, the start index is (N-1) * pageSize. The end index is min(startIndex + pageSize, totalItems).

Hint 3

Validate pageNumber bounds — throw or return an empty page for out-of-range requests.

Approach

Index Calculation

Page N (1-indexed): startIndex = (pageNumber - 1) * pageSize, endIndex = min(startIndex + pageSize, items.size). Total pages: ceil(items.size / pageSize.toFloat()).toInt().

What most candidates miss
  • Off-by-one on the last page when items don't divide evenly
  • Not validating out-of-bounds page numbers
  • Using 0-indexed pages when the spec says 1-indexed

Show the Kotlin solution
data class Page<T>(
    val items: List<T>,
    val currentPage: Int,
    val totalPages: Int,
    val hasNext: Boolean,
    val hasPrevious: Boolean
)

class PaginationManager<T>(
    private val allItems: List<T>,
    private val pageSize: Int
) {
    init { require(pageSize > 0) { "pageSize must be positive" } }

    private val totalPages = ceil(allItems.size / pageSize.toDouble()).toInt()

    fun getPage(pageNumber: Int): Page<T> {
        require(pageNumber in 1..totalPages) { "Page $pageNumber is out of range 1..$totalPages" }
        val start = (pageNumber - 1) * pageSize
        val end = minOf(start + pageSize, allItems.size)
        return Page(
            items = allItems.subList(start, end),
            currentPage = pageNumber,
            totalPages = totalPages,
            hasNext = pageNumber < totalPages,
            hasPrevious = pageNumber > 1
        )
    }

    fun nextPage(currentPage: Int): Page<T>? = if (currentPage < totalPages) getPage(currentPage + 1) else null

    fun previousPage(currentPage: Int): Page<T>? = if (currentPage > 1) getPage(currentPage - 1) else null
}

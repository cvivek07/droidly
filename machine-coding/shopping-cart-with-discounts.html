Shopping Cart with Discounts in Kotlin

Model a shopping cart with sealed-class discounts in Kotlin. A common Android machine coding round question, solved in the browser and checked by tests.

By Vivek Choudhary, Android engineer · Updated October 2026

Problem

Design a Shopping Cart that supports multiple discount types using Kotlin's sealed classes.

Discount Types
  • PercentageOff — e.g. 20% off item price
  • FlatDiscount — e.g. ₹200 off the item
  • BuyXGetYFree — e.g. buy 2 get 1 free (pay for ceil(quantity / (buy+free) × buy) items)
Functional Requirements
  • addItem(item) — Add to cart or increase quantity if already present
  • removeItem(productId) — Remove item from cart
  • calculateTotal() — Return total price after all discounts
  • getAppliedDiscounts() — Return map of productId → discount amount saved

What the tests check

  • an item without a discount costs price × quantity
  • PercentageOff: 2 × 1000 with 20% off = 1600
  • FlatDiscount: 2000 − 200 = 1800
  • FlatDiscount larger than the price floors at 0
  • BuyXGetYFree: buy 2 get 1 → 3 socks cost 2, 5 socks cost 4
  • adding the same product again increases its quantity
  • removeItem removes the product
  • full cart total is 3600 and savings are listed per product

Hints

Hint 1

Use a sealed class for Discount types. Each subtype carries different parameters — this is exactly what sealed classes are designed for.

Hint 2

In calculateTotal(), use a when expression on the Discount type for each item. For BuyXGetYFree: if you buy 3 with buy=2,free=1, you pay for 2.

Hint 3

For BuyXGetYFree: paidQuantity = ceil(quantity / (buyQuantity + freeQuantity).toFloat()) * buyQuantity

Approach

Sealed Class Dispatch

Use when (item.discount) in calculateTotal. Each branch handles its discount math. Store items in a MutableMap<String, CartItem> for O(1) add/update/remove by productId.

What most candidates miss
  • BuyXGetYFree calculation — most get the formula wrong for non-divisible quantities
  • Flat discount exceeding item price — should floor at 0, not go negative
  • Not handling duplicate addItem (should accumulate quantity, not replace)

Reference solution

sealed class Discount {
    data class PercentageOff(val percentage: Double) : Discount()
    data class FlatDiscount(val amount: Double) : Discount()
    data class BuyXGetYFree(val buyQuantity: Int, val freeQuantity: Int) : Discount()
    object None : Discount()
}

data class CartItem(
    val productId: String,
    val name: String,
    val price: Double,
    val quantity: Int,
    val discount: Discount = Discount.None
)

class ShoppingCart {
    private val items = LinkedHashMap<String, CartItem>()

    fun addItem(item: CartItem) {
        val existing = items[item.productId]
        items[item.productId] = existing?.copy(quantity = existing.quantity + item.quantity) ?: item
    }

    fun removeItem(productId: String) { items.remove(productId) }

    fun calculateTotal(): Double = items.values.sumOf { lineTotal(it) - saving(it) }

    fun getAppliedDiscounts(): Map<String, Double> =
        items.values.associate { it.productId to saving(it) }.filterValues { it > 0.0 }

    private fun lineTotal(item: CartItem) = item.price * item.quantity

    private fun saving(item: CartItem): Double = when (val d = item.discount) {
        is Discount.PercentageOff -> lineTotal(item) * d.percentage / 100.0
        is Discount.FlatDiscount -> minOf(d.amount, lineTotal(item))          // never below zero
        is Discount.BuyXGetYFree -> {
            val group = d.buyQuantity + d.freeQuantity
            val freeUnits = (item.quantity / group) * d.freeQuantity
            freeUnits * item.price
        }
        Discount.None -> 0.0
    }
}

HARDCoroutines & Flow
Your checkout screen calls 3 APIs in parallel. If any one fails, cancel the rest and show an error. How do you build it?

Use coroutineScope with three async calls. If one child fails, the scope cancels its siblings and rethrows, so you handle the error in one place.

val checkout = try {
    coroutineScope {
        val user = async { api.user() }
        val cart = async { api.cart() }
        val offers = async { api.offers() }
        Checkout(user.await(), cart.await(), offers.await())
    }
} catch (e: IOException) {
    null   // one failed: the others were cancelled
}

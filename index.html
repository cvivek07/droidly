Coroutines & Flow Hard
Your checkout screen calls 3 APIs in parallel. If any one fails, cancel the rest and show an error. How do you implement this?
// Parallel, fail fast val results = coroutineScope { val u = async { fetchUser() } val c = async { fetchCart() } val a = async { fetchAddress() } listOf(u, c, a).awaitAll() }
💡 Think about which calls are independent vs dependent. Independent calls can run with async { } inside a coroutineScope { } — if any one throws, the scope cancels the rest automatically.
Answer. Wrap the calls in coroutineScope { } and start each with async { }. They run in parallel, and if any one throws, the scope cancels its siblings and rethrows to the caller (structured concurrency gives you fail-fast for free). Call await() on each result and catch the exception around the whole scope to show your error state. Use supervisorScope only if you want one failure not to cancel the others.
